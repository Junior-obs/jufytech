# SNSHOP PORTFOLIO — UX RULES

# OBJECTIF

Créer une expérience utilisateur premium.

---

# PRIORITÉS

Le portfolio doit :
- convertir,
- impressionner,
- inspirer confiance,
- guider l'utilisateur.

---

# IMPORTANT

L'utilisateur doit immédiatement penser :

"Ce développeur semble très professionnel."

---

# ÉVITER

- surcharge visuelle,
- mauvaise lisibilité,
- sections trop chargées,
- animations inutiles,
- contrastes faibles.

---

# MOBILE UX

Sur mobile :
- réduire certaines animations,
- conserver fluidité,
- garder lisibilité.
